ℹ️ How Hybrid Encryption Works

🔑

Step 1: Key Pair

Generate an RSA-2048 key pair. Share your public key; keep your private key secret.

⚡

Step 2: AES Session Key

A random 256-bit AES key is generated fresh for every single message.

🔒

Step 3: AES-GCM Encrypt

Your message is encrypted with the AES key using AES-256-GCM, which also provides integrity (AEAD).

🛡️

Step 4: RSA-OAEP Wrap

The AES key is encrypted with the recipient's RSA public key using OAEP + SHA-256.

📦

Step 5: Bundle

The ciphertext, nonce, and encrypted AES key are bundled as a JSON payload.

🔓

Step 6: Decrypt

Only the holder of the matching private key can reverse the process and read the message.

🛡️ Security Notes

  • Keys are generated fresh on-demand and never stored on any server.
  • Your private key is shown once and must be downloaded immediately.
  • AES-GCM provides both confidentiality and authenticated integrity — tampering is detected.
  • RSA-OAEP with SHA-256 is resistant to chosen-ciphertext attacks.
  • All cryptographic operations run server-side via the Python cryptography library.
